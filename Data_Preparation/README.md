
Data Preparation Folder

This folder contains all datasets generated during the data preprocessing stage
of the Customer Churn Analysis project.

Contents:
- preprocessed_dataset.csv: Cleaned dataset with missing values handled and
  categorical variables encoded.
- X_train.csv: Training feature dataset.
- X_test.csv: Testing feature dataset.
- y_train.csv: Training target labels.
- y_test.csv: Testing target labels.

All preprocessing steps were performed to ensure data quality, consistency,
and readiness for predictive modelling.
